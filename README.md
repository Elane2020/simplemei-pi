# Projeto: Sistema simpleMEI (Desktop)

## Status
Em desenvolvimento

## Tecnologias utilizadas
JAVA e MySQL

## Time de Desenvolvedores
Elane dos Anjos

## Objetivos do software
Simplificar a gestão financeira de Microempreendedores Individuais, disponibilizando funcionalidades para cadastro de clientes e fornecedores, registro de movimentações financeiras e emissão de relatório gerencial.

## Funcionalidades do sistema 

- Cadastro e manutenção de clientes e fornecedores
- Registro de movimentações financeiras (receitas, despesas/custos e compras)
- Configuração dos dados cadastrais da empresa 
- Emissão de relatório por período
- Permissões de usuários
- Backup do sistema
